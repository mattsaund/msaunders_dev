GoDash

Your whole drive on one dashboard.

GoDash is an iOS app I designed and built that turns an iPhone in a hands-free car mount into a proper dash cam — one that also handles navigation, music, and live vehicle telemetry without ever making you switch apps at 70 mph.

01 Overview

Every drive already involves three or four apps fighting for the same screen: a dash cam recording in the background, maps in the foreground, music somewhere underneath, and none of them aware of each other. GoDash collapses that into a single interface built around one rule — nothing on screen should require more than a glance.

The phone's rear camera records continuously into a rolling buffer. Navigation and music live in half-screen modules that can be open at the same time, so the thing you need next is always already visible. Underneath both, a persistent readout shows what the vehicle is actually doing — speed, g-force, heading, altitude, and trip distance — sampled live and burned into saved footage.

It ships free with basic recording. GoDash Pro unlocks higher resolution, longer loops, the telemetry overlay, and crash detection.

02 Features

[ REC ]

Loop recording

A continuous rolling buffer holds up to ten minutes of driving. One tap writes the current buffer to the device as a permanent clip — no scrubbing, no file management, no waiting until you get home.

[ TELEM ]

Live telemetry overlay

Speed, g-force, heading, altitude, and trip distance are sampled while you drive and composited directly onto saved clips, so the footage carries its own context instead of needing a separate log.

[ NAV ]

Turn-by-turn navigation

Apple Maps directions run inside a module rather than in another app. Full-height when you need the route, collapsed to a single instruction card when you do not.

[ AUDIO ]

Apple Music, in place

Browse, play, and skip without leaving the recording session. Pairs with navigation in a split view so both are on screen at once.

[ SAFETY ]

Crash detection

Motion thresholds for collisions and hard braking automatically preserve the footage from before, during, and after the event — the window you actually need, saved without you touching the phone.

[ LIB ]

Clips & export

Saved clips are organised chronologically with in-app playback and one-step export to the Photos library.

03 How it works

The recording pipeline

Capture runs off the rear camera through AVFoundation into a fixed-length ring of video segments. Old segments are discarded as new ones are written, which keeps storage bounded no matter how long the drive is. A save request stitches the segments currently in the ring into a single clip — the ten minutes leading up to the moment you decided you wanted them.

Telemetry

CoreMotion supplies acceleration for g-force, and CoreLocation supplies speed, heading, and altitude. Samples are timestamped against the capture clock so the overlay lines up with the frame it describes rather than drifting across a long clip. Trip distance accumulates across the session.

The module system

The interface is a stack of resizable modules rather than a set of screens. Navigation and music each render at full or compact height, and the layout is designed so any pairing is reachable in a single gesture. This is the part I have iterated on most — the design target is that a driver can restore the layout they want by feel, without reading the screen.

Crash detection

A motion threshold on sustained deceleration and impact-scale acceleration flags an event. When one fires, the buffer around it is locked and written out immediately, before the ring can overwrite the segments that matter.
